Como funciona

Escolha o documento no menu ao lado, preencha os dados do cliente e do caso, clique em "Gerar / Atualizar documento" para ver a prévia, ajuste o texto se quiser, e baixe em Word (.doc) ou imprima/salve em PDF. Nada daqui sincroniza com o Tramitação Inteligente — os dados do cliente são digitados na hora, em cada documento.

Backup dos dados

Os dados ficam só neste navegador. Exporte um backup regularmente — obrigatório antes de limpar o cache/histórico do navegador ou trocar de computador.
